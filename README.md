# 🚀 Proyectos destacados

### 🤖 Pitágoras: plataforma educativa con IA

🏆 Hackathon NEXIA 2026 · Líder del equipo

Plataforma de preparación para exámenes de admisión con simulacros, diagnóstico académico y tutores basados en IA.

**Qué desarrollé**
- API backend con FastAPI (~80 endpoints REST) organizada por módulos
- Autenticación con JWT
- Persistencia con MySQL y SQLAlchemy, con esquema SQL y migraciones
- Tutores con RAG usando ChromaDB y sentence-transformers
- Orquestación de agentes con LangGraph
- Integración con la aplicación Flutter

**Stack:** Python · FastAPI · SQLAlchemy · MySQL · Docker · LangGraph · ChromaDB · Flutter

🔗 [Repositorio](https://github.com/naohan/pitagoras_final)

### 🗺️ SIRI: priorización de fiscalización minera

🏆 Finalista (Top 10) Geotón Perú 2026 (PCM) · Proyecto individual

Motor de análisis espacial que cruza concesiones mineras con áreas protegidas, deforestación, focos de calor y ríos para priorizar qué concesiones fiscalizar.

**Qué desarrollé**
- Índice de riesgo ambiental y ranking de concesiones prioritarias
- Análisis geoespacial con GeoPandas, Shapely y Rasterio (estadística zonal)
- API REST con FastAPI (~18 endpoints)
- Mapa interactivo con React y Leaflet, desplegado con Nginx

**Stack:** Python · FastAPI · GeoPandas · Shapely · Rasterio · React · Leaflet

🔗 [Repositorio](https://github.com/naohan/Geothon-SIRI) · 🌐 [Demo](http://2.25.102.3/geoton/)

### 📡 IoT Operations Center

Monitoreo de sensores de temperatura y humedad en tiempo real, con alertas y acceso por roles.

**Qué desarrollé**
- Ingesta de datos por MQTT (Mosquitto) con validación y almacenamiento en PostgreSQL
- Detección de anomalías por dispositivo con scikit-learn (Isolation Forest)
- API REST con FastAPI, JWT y tres roles (viewer, operator, admin)
- Actualizaciones en vivo por WebSocket
- Despliegue de todo el sistema con Docker Compose

**Stack:** Python · FastAPI · PostgreSQL · MQTT · scikit-learn · Docker · Angular

🔗 [Repositorio](https://github.com/naohan/iot-operations-center)

### 🫀 ALEXTRIX HealthConnect

🥈 2.º puesto, Laboratorio de Emprendimiento TECSUP

Monitoreo de salud en tiempo real desde un smartwatch Wear OS.

**Qué desarrollé**
- API REST con FastAPI y SQLAlchemy sobre PostgreSQL
- Recepción de pulso y GPS desde la app Wear OS (Kotlin)
- Alertas calculadas en el servidor cuando el pulso sale de rango
- Panel en tiempo real por WebSocket, con gráfico y mapa
- Despliegue en VPS con Nginx y Uvicorn

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · WebSocket · Kotlin (Wear OS)

🔗 [Repositorio](https://github.com/naohan/ALEXTRIX) · 🌐 [Demo](http://2.25.102.3/alextrix/)

### 😴 Medición de descanso

Backend que convierte los datos de un Xiaomi Watch 2 en información de sueño y fatiga.

**Qué desarrollé**
- API REST con FastAPI, SQLAlchemy y PostgreSQL (~14 endpoints)
- Ingesta por lotes de frecuencia cardíaca y sesiones de sueño
- Detección de la sesión principal de cada noche, estimación de HRV y resúmenes diarios
- Integridad de datos con restricciones UNIQUE y migración que elimina duplicados
- Protección opcional con API key

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · Pydantic

🔗 [Repositorio](https://github.com/naohan/medicion-descanso)

### 🛺 FiscaMoto: fiscalización de mototaxis, Municipalidad de La Joya

📱 App publicada en Google Play · Líder del proyecto

Plataforma de control y fiscalización de mototaxis con evidencia fotográfica.

**Qué desarrollé**
- App Android en Kotlin con Jetpack Compose para los fiscalizadores en campo
- Inicio de sesión y sesión guardada con DataStore
- Envío periódico de ubicación GPS
- Consumo de API REST con Retrofit y comunicación en tiempo real con Socket.IO
- Correcciones puntuales en la plataforma web en la etapa final

**Stack:** Kotlin · Jetpack Compose · Retrofit · Socket.IO · APIs REST

🔗 [Repositorio](https://github.com/naohan/FiscamotoGPS) · 📲 [Google Play](https://play.google.com/store/apps/details?id=com.munilajoya.fiscamoto)
